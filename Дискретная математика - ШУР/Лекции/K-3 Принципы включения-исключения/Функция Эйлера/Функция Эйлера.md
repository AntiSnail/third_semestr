# Функция Эйлера

>[!definition] Функция Эйлера
>Натуральные числа $m$ и $k$ *взаимно просты*, если $\text{НОД}(m,k) = 1$
>Количество чисел $i \in [1\dots n]$, взаимно простых с $n$, обозначается через $\phi(n)$
>$\phi(n)$ - *функция Эйлера*

>[!theorem] Теорема:
>Пусть $n = p_{1}^{r_{1}}p_{2}^{r_{2}}\dots p_{k}^{r_{k}}$ - разложение числа $n$ на простые множители. Тогда
>$$\phi(n) = n \prod_{i=1}^k\left( 1 - \frac{1}{p_{i}} \right)$$

>[!proof]- Доказательство:
>положим $A = [1\dots n]$, $A_{i} = \{j | j \text{ кратно } p_{i}\}$
>$\Rightarrow |A_{i}| = \frac{n}{p_{i}}$
>так как все $p_{i}$ - простые, $|A_{i_{1}} \cap \dots \cap A_{i_{j}}| = \frac{n}{p_{i_{1}}\dots p_{i_{j}}}$
>применим ПВИ в общей форме:
>$\phi(n) = n - \sum_{i=1}^k \frac{n}{p_{i}} + \dots + (-1)^j \cdot \sum_{i_{1} < \dots < i_{j}}\frac{n}{p_{i_{1}}\dots p_{i_{j}}} + \dots + (-1)^k \frac{n}{p_{1}\dots p_{k}}$
>оказывается, $\prod_{i=1}^k\left( 1 - \frac{1}{p_{i}} \right) = 1 - \sum_{i=1}^k \frac{1}{p_{i}} + \dots + (-1)^j \cdot \sum \frac{1}{p_{i_{1}}\dots p_{i_{j}}} + \dots + (-1)^k \frac{1}{p_{1}\dots p_{k}}$
