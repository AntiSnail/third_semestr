# ПВИ: вторая версия

>[!corollary] Формула ПВИ в другом виде
>Перепишем формулу [[ПВИ для k множеств|(1)]] в виде
>$$|\bigcup_{i=1}^k A_{i}| = \sum_{j=1}^k (-1)^{j-1}(\sum_{X \subseteq [1\dots k], |X|=j}|\bigcap_{i \in X}A_{i}|)$$
>
>Пусть для $j = 1,\dots,k$
>$N_{j} = (\sum_{X \subseteq[1\dots k],|X|=j}|\bigcap_{i \in X}A_{i}|$; доопределим $N_{0} = |A|$
>
>Тогда число элементов, не обладающих ни одним из $k$ свойств, есть:
>$|A \setminus \bigcup_{i=1}^k A_{i}| = |A| - |\bigcup_{i=1}^k A_{i}| = N_{0} - \sum_{j=1}^k (-1)^{j-1}N_{j} = N_{0} + \sum_{j=1}^k (-1)^jN_{j} = \sum_{j=0}^k(-1)^jN_{j}$
>
>*Симметричный* вариант ПВИ: пусть $|\bigcap_{i \in X}A_{i}| = s_{|X|}$ зависит только от $|X|$; тогда
>$N_{j} = \begin{pmatrix}k \\ j\end{pmatrix}s_{j}$
