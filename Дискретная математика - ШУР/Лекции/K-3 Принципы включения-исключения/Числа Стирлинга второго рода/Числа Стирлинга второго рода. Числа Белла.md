# Числа Стирлинга второго рода. Числа Белла

>[!definition] Числа Стирлинга второго рода
>*Числом Стирлинга второго рода* называется число $\left\{\begin{matrix}n \\ k\end{matrix}\right\}$ разбиений $n$-элементного множества на $k$ классов
>- или число отношений эквивалентности с $k$ классами на $n$-элементном множестве

>[!example] Пример:
>$\left\{\begin{matrix}4 \\ 2\end{matrix}\right\} = 7$
>$\{1,2,3\}\{4\}; \ \{1,2,4\}\{3\}; \ \{1,3,4\}\{2\}; \ \{2,3,4\}\{1\}; \ \{1,2\}\{3,4\}; \ \{1,3\}\{2,4\}; \ \{1,4\}\{2,3\}$

>[!definition] Числа Белла:
>*Числом Белла* называется число $B(n)$ разбиений $n$-элементного множества
>- $B(n) = \sum_{k=1}^n \left\{\begin{matrix}n \\ k\end{matrix}\right\}$

>[!theorem] Теорема
>$\left\{\begin{matrix}n \\ k\end{matrix}\right\} = \frac{sur(n,k)}{k!} = \frac{1}{k!}\sum_{j=0}^k(-1)^{k-j}\begin{pmatrix}k \\ j\end{pmatrix}j^n$

>[!proof]- Доказательство:
>пусть $B,C$ - множества, $|B| = n, \ |C|=k$
>любая сюръекция $f: B \to C$ задает отношение эквивалентности $\sim_{f}$ на $B$:
>- $a \sim_{f} b \Leftrightarrow f(a) = f(b)$
>$f$ задает разбиение $B$ на $k$ классов
>любое разбиение $B$ на $k$ классов можно задать сюръекцией, «назначив» каждому классу свой элемент из $C$
>сюръекций, задающих фиксированное разбиение $B$ на $k$ классов, столько же, сколько способов назначить классам элементы из $C$, т.е. $k!$
>$\Rightarrow$ получили $\left\{\begin{matrix}n \\ k\end{matrix}\right\} = \frac{sur(n,k)}{k!}$
