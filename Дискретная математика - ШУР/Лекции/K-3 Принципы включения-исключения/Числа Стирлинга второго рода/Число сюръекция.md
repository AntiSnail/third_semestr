# Число сюръекций

>Пусть $B$ и $C$ - множества, $|B| = n, |C| = k$
>Существует $k^n$ различных функций из $B$ в $C$
>- $k$ способов выбрать образ для каждого из $n$ элементов

>[!theorem] Теорема:
>Число сюръекций $n$-элементного множества $B$ на $k$-элементное множество $C$ равно
>$$sur(n,k) = \sum_{j=0}^k (-1)^{k-j}\begin{pmatrix}k \\ j\end{pmatrix}j^n$$

>[!proof]- Доказательство:
>Пусть $A = \{f: B \to C\}, \ C = \{c_{1},\dots,c_{k}\}$
>возьмем следующие свойства $P_{1},\dots,P_{k}$ элементов $A$:
>- $P_{i} =$ «образ функции не содержит элемента $c_{i}$»
>$\Rightarrow |A_{i}| = (k-1)^n \ \ \ \forall i$
>более того, $|\bigcap_{i \in X}A_{i}| = (k - |X|)^n$
>$\Rightarrow$ можно воспользоваться [[ПВИ вторая версия|симметричным ПВИ]] с $s_{j} = (k-j)^n$
>$\Rightarrow sur(n,k) = \sum_{j=0}^k(-1)^j \begin{pmatrix}k \\ j\end{pmatrix}(k-j)^n = \sum_{j=0}^k(-1)^j \begin{pmatrix}k \\ k-j\end{pmatrix}(k-j)^n = \sum_{j=0}^k (-1)^{k-j}\begin{pmatrix}k \\ j\end{pmatrix}j^n$
