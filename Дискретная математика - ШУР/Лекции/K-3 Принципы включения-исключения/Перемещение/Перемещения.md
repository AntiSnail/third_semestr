# Перемещения

>[!definition] Перемещение
>Перестановка $\sigma \in S_{n}$ называется *перемещением*, если $\sigma(i) \neq i \ \ \ \forall i$
>- используется также термин *полны беспорядок*
>
>Пусть $D(n)$ - число перемещений $n$-элементного множества

>[!theorem] Теорема
>$D(n) = n! \sum_{i=0}^n \frac{(-1)^i}{i!}$

>[!proof]- Доказательство:
>Положим $A = S_{n}, \ A_{i} = \{\sigma | \sigma(i) = i\}$
>на $\sigma \in A_{i}$ можно смотреть как на перестановку множества $[1\dots n] \setminus\{i\}$
>$\Rightarrow |A_{i}| = (n-1)!$
>$\Rightarrow$ аналогично, для любого $X \subseteq [1\dots n], \ |\bigcap_{i \in X}A_{i}| = (n- |X|)!$
>применим [[ПВИ вторая версия|симметричный ПВИ]]
>$D(n) = |A \setminus \bigcup_{i \in X} A_{i}| = \sum_{j=0}^n (-1)^j \begin{pmatrix}n \\ j\end{pmatrix}(n-j)! = \sum_{j=0}^n (-1)^j \frac{n!}{j!(n-j)!}(n-j)! = n! \sum_{i=0}^n \frac{(-1)^j}{j!}$

>[!corollary] Следствие:
>$\frac{D(n)}{n!} = \sum_{i=0}^{n} \frac{(-1)^i}{i!} \to_{n\to \infty} \frac{1}{e}$
