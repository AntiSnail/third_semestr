# Операции над отношениями как матричные операции:

>[!definition] Булевы матрицы:
> *Булевы матрицы* - это матрицы с элементами из $\{0, 1\}$
>- единичная матрица $E$ является булевой
>	- $E$ - матрица отношения равенства, обозначаемого $\Delta$
>- Операции над булевыми матрицами:
>	- конъюнкция $\wedge$, дизъюнкция $\vee$, отрицание $\overline{}$, выполняемые поэлементно
>- транспонирование
>	- [[Умножение отношений и умножение матриц|булево умножение]]

| Операция    | Определение                                                                            | Матричные вычисления                               |
| ----------- | -------------------------------------------------------------------------------------- | -------------------------------------------------- |
| объединение | $\rho \cup \sigma = \{(a,b) \in A^2 \| (a,b) \in \rho \text{ или } (a,b) \in \sigma\}$ | $M_{\rho \cup\sigma} = M_{\rho} \vee M_{\sigma}$   |
| пересечение | $\rho \cup \sigma = \{(a,b) \in A^2 \| (a,b) \in \rho \text{ и } (a,b) \in \sigma\}$   | $M_{\rho \cup\sigma} = M_{\rho} \wedge M_{\sigma}$ |
| дополнение  | $\overline{\rho} = \{(a,b) \in A^2 \| (a,b) \not\in  \rho\}$                           | $M_{\overline{\rho}} = \overline{M_{\rho}}$        |
| обращение   | $\rho^{-1} = \{(a, b) \in A^2 \| (b,a) \in \rho\}$                                     | $M_{\rho^{-1}} = M_{\rho}^T$                       |
