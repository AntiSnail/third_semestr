# Характеристический многочлен и частные решения

>[!definition] Характеристический многочлен
>Многочлен $\chi(x) = x^k - a_{1}x^{k-1} - \dots - a_{k-1}x - a_{k}$ называется [[4. Archive/Алгем/Лекции 2 семестр/лекции/9 лекция#^e19822|характеристическим многочленом]] рекуррентного соотношения $f(n) = a_{1}f(n-1)+\dots+a_{k}f(n-k)$

>[!corollary] Лемма о частных решениях
>Пусть $\lambda \neq 0$. Функция $f(n) = \lambda^n$ является решением рекуррентного соотношения $f(n) = a_{1}f(n-1) + \dots + a_{k}f(n-k)$ тогда и только тогда, когда $\lambda$ - корень $\chi(x)$

^9104df

>[!proof]- Доказательство:
>при $\lambda \neq 0$
>$\lambda^n = a_{1}\lambda^{n-1} + \dots + a_{k}\lambda^{n-k} \Leftrightarrow \lambda^k = a_{1}\lambda^{k-1} + \dots + a_{k} \Leftrightarrow \lambda$ - корень $\chi(x)$
>
>Неважно, над каким полем рассматривать рекуррентное соотношение: если его рассматривать над $\mathbb{C}$, комплексные корни характеристического многочлена также дадут решения
