# Решение линейных рекуррентных соотношений первого порядка

>Запишем соотношение первого порядка в виде $f(n+1) = a(n)f(n) + b(n), \ \ \ f(0) = a$
>- при $a(n) = n + 1$ и $b(n) = 0$ получается факториал

>[!theorem] Теорема:
>$f(n) = a \cdot \prod_{i=0}^{n-1} a(i) + \sum_{j=0}^{n-1}\left( b(j)\prod_{k=j+1}^{n-1} a(k) \right)$

>[!proof]- Доказательство:
>Положим $g(n) = \frac{f(n)}{\prod_{i=0}^{n-1} a(i)} = f(0) = a$
>
>Запишем $f(n+1) - a(n)f(n) = b(n)$ и поделим обе части на $\prod_{i=0}^{n} a(i)$
>$\frac{f(n+1) - a(n)f(n)}{\prod_{i=0}^n a(i)} = \frac{b(n)}{\prod_{i=0}^n}a(i) \Rightarrow \frac{f(n+1)}{\prod_{i=0}^n a(i)} - \frac{f(n)}{\prod_{i=0}^{n-1}a(i)} = \frac{b(n)}{\prod_{i=0}^n a(i)}$
>$\Rightarrow g(n+1) - g(n) = \frac{b(n)}{\prod_{i=0}^n a(i)}$
>
>Подставляя последнее равенство в $g(n) - g(0) = \sum_{j=0}^{n-1} (g(j+1) - g(j))$, получим $g(n) = a + \sum_{j=0}^{n-1} \frac{b(n)}{\prod_{k=0}^j a(k)}$, откуда следует *(1)*
