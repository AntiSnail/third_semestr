# Неоднородные ЛРС с постоянными коэффициентами

>Что делать, если дано [[Классификация рекуррентных соотношений#^e81301|линейное неоднородное]] рекуррентное соотношение с постоянными коэффициентами?
>
>$f(n) = a_{1}f(n-1) + \dots + a_{k}f(n-k) + h(n)$ для некоторой функции $h(n)$
>
>Возможная стратегия - перейти к однородному соотношению более высокой степени

>[!example] Примеры:
>Пусть $f(n) = a_{1}f(n-1) + \dots + a_{k}f(n-k) + c$, где $c$ - константа
>$f(n) - f(n-1) = a_{1}(f(n-1) - f(n-2)) + \dots + a_{k}(f(n-k) - f(n-k-1))$
>$\Rightarrow f(n) = (a_{1}+1)f(n-1) + (a_{2}-a_{1})f(n-2) + \dots + (a_{k}-a_{k-1})f(n-k) - a_{k}f(n-k-1)$
>задали линейным однородным соотношением порядка $k+1$
>
>---
>
>Если $p(n)$ - многочлен степени $m$, то $(p(n) - p(n-1))$ имеет степень $m-1$
>Пусть $f(n) = a_{1}f(n-1) + \dots + a_{k}f(n-k) + p(n)$, где степень $p(n)$ равна $m$
>записав $f(n) - f(n-1)$, можно выразить $f(n)$ соотношением порядка $k+1$, в котором неоднородность является многочленом $p(n) - p(n-1)$ степени $m-1$
>$\Rightarrow$ повторив процедуру еще $m$ раз, получим однородное соотношение порядка $m+k+1$
>
>---
>
>Пусть $f(n) = a_{1}f(n-1) + \dots + a_{k}f(n-k) + c \cdot d^n$, где $c,d$ - константы
>записав $f(n) - d \cdot f(n-1)$, можно выразить $f(n)$ однородным соотношением порядка $k+1$
