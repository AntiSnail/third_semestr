# Интеграл Эйлера

>Вычислим $E(n) = \int_{0}^\infty x^ne^{-x}$, где $n \in \mathbb{N}$
>
>$E(0) = \int_{0}^\infty e^{-x}dx = -e^{-x}|_{0}^\infty = 0 - (-1) = 1$
>
>К $E(n)$ применим интегрирование по частям:
>$E(n) = \int_{0}^\infty x^ne^{-x}dx = \begin{equation}\left[	\begin{array}{ll}		u = x^n \\		dv = e^{-x}dx \\ du = nx^{n-1}dx \\ v = -e^{-x}	\end{array}\right]\end{equation} =$
>$= x^n(-e^{-x})|_{0}^\infty - \int_{0}^\infty nx^{n-1}(-e^{-x})dx =$
>$= 0 + n\int_{o}^\infty x^{n-1}e^{-x}dx = nE(n-1)$
>
>$E(n)$ задается рекуррентным соотношением $E(n) = nE(n-1), E(0) = 1$
>$\Rightarrow E(n) = n!$
>Для вывода [[Биномиальные коэффициента - асимптотика#^aed492|формулы Стирлинга]] $n! \sim \sqrt{ 2\pi n }\left( \frac{n}{e} \right)^n$ оценивают интеграл Эйлера, т.е. площадь под графиком функции $f_{n}(x) = x^ne^{-x}$
