# Использование рекуррентных соотношений

>Можно выделить два основных типа задач на рекуррентные соотношения
>*1.* Дана (неконструктивно) функция $f$, требуется научиться ее вычислять
>   - пример: $f(n)$ есть число отношений эквивалентности на $n$-элементном множестве
>   - сюда же относится *метод динамического программирования*
>
>*2.*  Дана (рекуррентно) функция $f$, требуется найти *замкнутую* формулу для вычисления $f(n)$
>   - это называется *решить рекуррентное соотношение*
>   - можно решить его, угадав формулу и доказав ее *по индукции*
>   - для некоторых классов рекуррентных соотношений существуют универсальные методы решения
