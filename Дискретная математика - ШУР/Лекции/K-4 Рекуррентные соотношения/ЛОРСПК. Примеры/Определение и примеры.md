# Определение и примеры

>[!definition] ЛОРСПК
>*Линейное однородное рекуррентное соотношение с постоянными коэффициентами* имеет вид
>$f(n) = a_{1}f(n-1) + \dots + a_{k}f(n-k)$
>
>Если все коэффициенты $a_{1},\dots,a_{k}$ принадлежат кольцу $\mathbb{K}$, то $f: \mathbb{N} \to \mathbb{K}$

^0eb91d

>[!example] Примеры:
>$f(n) = q \cdot f(n-1)$
>- геометрическая прогрессия со знаменателем $q$ и первым членом $f(0)$
>
>$f(n) = f(n-1) + f(n-2)$
>- числа Фибоначчи при $f(0) = 0, f(1) = 1$
>
>$f(n) = f(n-1) + f(n-2) + f(n-3)$
>- числа Трибоначчи при $f(0) = 0, f(1) = 1, f(2) = 2$
>
>$f(n) = 2f(n-1) - f(n-3) + f(n-4)$
>- при $f(0) = 4, f(1) = 7, f(2) = 13, f(3) = 24$ - число маршрутов длины $n$ в графе
