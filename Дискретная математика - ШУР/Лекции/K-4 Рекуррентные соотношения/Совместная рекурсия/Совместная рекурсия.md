# Совместная рекурсия

>[!definition] Совместная рекурсия
>Существуют случаи *совместной рекурсии*, когда две функции (или больше) задаются при помощи рекуррентных соотношений, использующих предыдущие значения обеих функций
>
>Подобную «систему» рекуррентных соотношений иногда можно решить, преобразовав в обычные рекуррентные соотношения

>[!example] Пример:
>$\begin{equation}\left\{	\begin{array}{ll}		f(n) = 2g(n-1)  + f(n-2), \ \ \ f(0) = 1, f(1) = 0 \\		g(n) = f(n-1) + g(n-2), \ \ \ \ \ g(0) = 0, g(1) = 1	\end{array}\right.\end{equation}$
>
>$f(n) = 2g(n-1) + f(n-2) = 3f(n-2) + 2g(n-3) = 4f(n-2) - f(n-3)$
>$g(n) = f(n-1) + g(n-2) = 3g(n-2) + f(n-3) = 4g(n-2) - g(n-4)$
>
>характеристический многочлен: $x^4 - 4x^2 + 1$
>корни: $\pm \sqrt{ 2 \pm \sqrt{ 3 } }$
>можно честно решать систему четырех уравнений, но можно и упростить:
>$f(n) = 0$ при нечетных $n$ (по индукции) $\Rightarrow$ найдем $\overline{f}(n) = f(2n)$
>имеем $\overline{f}(n) = 4\overline{f}(n-1) - \overline{f}(n-2), \ \overline{f}(0) = 1, \overline{f}(1) = 3$
>корни: $2 \pm \sqrt{ 3 }$
>$\Rightarrow \begin{equation}\left\{	\begin{array}{ll}		C_{1} + C_{2} = 1 \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \overline{f}(0) = 1 \\		(2 + \sqrt{ 3 })C_{1} + (2 - \sqrt{ 3 })C_{2} = 3 \ \ \ \ \ \ \ \ \ \  \overline{f}(1)=3	\end{array}\right.\end{equation}$
>$\Rightarrow C_{1} = \frac{3+\sqrt{ 3 }}{6}, C_{2} = \frac{3 - \sqrt{ 3 }}{6}$
>$\Rightarrow \begin{equation}f(x)\left\{	\begin{array}{ll}		0, \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ n \text{ нечетно} \\		\left( \frac{3+\sqrt{ 3 }}{6} \right)(2+\sqrt{ 3 })^{\frac{n}{2}} + \left( \frac{3-\sqrt{ 3 }}{6} \right)(2 - \sqrt{ 3 })^{\frac{n}{2}} \ \ \ \ \ \ \ \ \ n \text{ четно}	\end{array} \right.\end{equation}$

>[!example] Пример задачи:
>*Задача:* сколькими способами можно замостить прямоугольник размера $3 \times n$ костяшками домино размера $2 \times 1$? Костяшки разрешено поворачивать
>
>Пусть число способов равно $f(n)$
>$f(n) = 0$ при нечетных $n$, для четных составим рекуррентное соотношение
>
>Все варианты замощения можно разбить на три группы по наличию или отсутствию костяшки, полностью лежащей в последнем столбце
>![[d3d6cfe5b820e4d295a2530e74695a3a.png|350]]
>$f(n) = f(n-2) + 2g(n-1)$
>где $g(n)$ - число способов замостить прямоугольник $3 \times n$, оставив непокрытой одну угловую клетку справа
>$g(n) = f(n-1) + g(n-2)$
>Функции $f(n)$ и $g(n)$ заданы системой рекуррентных соотношений
>$\begin{equation}\left\{	\begin{array}{ll}		f(n) = 2g(n-1)  + f(n-2), \ \ \ f(0) = 1, f(1) = 0 \\		g(n) = f(n-1) + g(n-2), \ \ \ \ \ g(0) = 0, g(1) = 1	\end{array}\right.\end{equation}$
