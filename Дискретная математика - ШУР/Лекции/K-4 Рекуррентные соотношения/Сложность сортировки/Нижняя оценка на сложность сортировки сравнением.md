# Нижняя оценка на сложность сортировки сравнением

>Существует алгоритм (*MergeSort*), сортирующий любой массив длины $n$ не более чем за $n(\log n - \log e + \log \log e) + 1$ сравнений символов

>[!theorem] Теорема
>Любой алгоритм *сортировки сравнением символов* делает при сортировке массива длины $n$ не менее $n\log n - n\log e + \frac{1}{2}\log n + O(1)$ сравнений в *худшем случае*

>[!proof]- Доказательство:
>алгоритм выполняет сравнения во входном массиве $A$ последовательно
>результат сравнения однозначно определяет следующее сравнение
>выполнив все сравнения, алгоритм знает [[Действие перестановки#^d22d2f|сортирующую перестановку]] массива $A$
>$\Rightarrow$ работу алгоритма можно представить *деревом решений*
>
>*Пример:* дерево для алгоритма сортировки трехэлементного массива $[a,b,c]$
>![[3bc57ca8e463e8edb760c6a36154cb7e.png|200]]
>
>дерево решения для сортировки - бинарное и имеет $\geqslant n!$ листьев
>$\Rightarrow$ на самом длинном пути от корня до листа не менее $\log n!$ сравнений
>по [[Биномиальные коэффициента - асимптотика#^aed492|формуле Стирлинга]]
>$\log n! = \log\left( \sqrt{ 2\pi n }\left( \frac{n}{e} \right)^n \right) + o(1) = n\log n - n\log e + \frac{1}{2}\log n + O(1)$
>
>*MergeSort* делает не более $n \cdot \log \log e \sim \frac{n}{2}$ «лишних» сравнений
