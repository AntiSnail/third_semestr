# Лемма о следствии

>[!definition] Лемма
>Для любых булевых формул $X, Y, Z$ формула $Y \vee Z$ - следствие формулы $(X \vee Y) \wedge (\overline{X} \vee Z)$

>[!proof]- Доказательство:
>пусть $F_{|\vec{b}}$ обозначает результат подстановки набора значений $\vec{b}$ в формулу $F$
>пусть $\vec{b}$ - произвольный набор, такой что $((X \vee Y) \wedge (\overline{X} \vee Z))_{|\vec{b}} = 1$
>$\Rightarrow (X \vee Y)_{|\vec{b}} = 1, (\overline{X} \vee Z)_{|\vec{b}} = 1$
>если $X_{|\vec{b}} = 1$, то $\overline{X}_{|\vec{b}} = 0 \Rightarrow Z_{|\vec{b}} = 1$
>если $X_{|\vec{b}} = 0$, то $Y_{|\vec{b}} = 1$
>$\Rightarrow (Y \vee Z)_{|\vec{b}} = 1$
>$\Rightarrow ((X \vee Y) \wedge (\overline{X} \vee Z)) \to (Y \vee Z)$ - тавтология
