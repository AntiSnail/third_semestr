# Распространение переменной

>Пусть КНФ состоит из клозов $C_{1},\dots,C_{l}$ и зависит от переменных $x_{1},\dots,x_{n}$
>можно считать, что КНФ $F$ задана двумя массивами:
>$L[1\dots 2n]:$ в $L[i]$ хранится список номеров клозов, в которые входят литерал $x_{i}$ (при $i \leqslant n$) либо литерал $\overline{x}_{i-n}$ (при $i > n$)
>$C[1\dots l]:$ в $C[i]$ хранится список номеров литералов, которые входят в клоз $C_{i}$ (номер $i > n$ означает литерал $\overline{x}_{i-n}$)
>при переводе КНФ в такую форму можно сразу отбросить клозы, содержащие два противоположных литерала одновременно

>[!definition] Распространение переменной
>*Распространение переменной* (unit propogation) - процедура упрощения КНФ
>если в $F$ есть клоз, состоящий из единственного литерала ($x_{i}$ либо $\overline{x}_{i}$), то набор $(b_{1},\dots,b_{n})$ выполняет $F$ только при условии, что $b_{i}$ выполняет данный клоз
>$\Rightarrow$ значение $b_{i}$ определено однозначно
>пусть литерал равен $x_{i}$, т.е. $b_{i} = 1$; случай $b_{i} = 0$ аналогичен
>$\Rightarrow$ можно присвоить значение $b_{i}$ и упростить формулу:

^3adfdc

>*(1)* клозы, содержащие $x_{i}$, выполнены - их можно удалить
>*(2)* из клозов, содержащих $\overline{x}_{i}$, можно удалить этот литерал (он равен $0$)
>если получился пустой клоз, то $F$ невыполнима
>можно создать очередь одноэлементных клозов
>очередь пополняется при выполнении пункта *(2)*
>распространение переменной выполняется в цикле, пока очередь непуста

>КНФ $F \to^{\text{распространение переменной}}$ КНФ $UP(F)$
>$UP(F) = 1$, если удалены все клозы
>$UP(F) = 0$, если встретился пустой клоз
>$UP(F)$ выполнима $\Leftrightarrow F$ выполнима
>
Распространение переменной выполняется за время $O$(число литералов в $F$) 

>[!example] Пример:
>$F = (a \vee d) \wedge (c \vee d \vee \overline{a}) \wedge (\overline{b} \vee \overline{c} \vee \overline{d}) \wedge (\overline{a}) \wedge (a \vee b \vee \overline{c})$
>в очереди единственный клоз $\overline{a}$, достаем его
>*(1)* удаляем клозы $\overline{a}$ и $c \vee d \vee \overline{a}$
>*(2)* удаляем $a$ из клозов $a \vee b \vee \overline{c}$ и $a \vee d$ (новый клоз $d$ добавляем в очередь)
>текущий список клозов: $d, \overline{b} \vee \overline{c} \vee \overline{d}, b \vee \overline{c}$
>достаем клоз $d$ из очереди
>*(1)* удаляем клоз $d$
>*(2)* удаляем $\overline{d}$ из клоза $\overline{b} \vee \overline{c} \vee \overline{d}$
>очередь пуста, получаем $UP(F) = (b \vee \overline{c}) \wedge (\overline{b} \vee \overline{c})$
>$UP(F)$ можно выполнить, положив $c = 0$
>$\Rightarrow$ набор $a = 0, c = 0, d = 1$ выполняет $F$ (при любом $b$)

>Дополнение к распространению переменной: правило *чистой переменной*
>если в результате удаления клоза  *(1)* у литерала не осталось вхождений в формулу, то переменной этого литерала присваивается значение, превращающее этот литерал в $0$
>это позволяет выполнить все клозы, содержащие противоположный литерал, и тем самым упростить текущую КНФ
>когда в примере получено $UP(F) = (b \vee \overline{c}) \wedge (\overline{b} \vee \overline{c})$, литерал $c$ не имеет вхождений, и присвоение $c = 0$ позволяет выполнить оба оставшихся клоза
>

>В дальнейшем под $UP(F)$ мы понимаем формулу, полученную из $F$ применением обоих правил
