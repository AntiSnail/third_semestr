# Монотонные функции

>[!definition] Покомпонентный порядок
>Введем на битовых векторах равной длины *покомпонентный порядок*
>$(x_{1},\dots,x_{k}) \leqslant (y_{1},\dots,y_{k}) \Leftrightarrow x_{1}\leqslant y_{1},\dots,x_{k}\leqslant y_{k}$
>[[4. Archive/Дискретная математика/лекции/M-2 Упорядоченные множества/Отношения порядка и диаграммы Хассе/Отношения порядка#^f37963|диаграмма Хассе]] [[4. Archive/Дискретная математика/лекции/M-2 Упорядоченные множества/Отношения порядка и диаграммы Хассе/Отношения порядка#^444df8|ЧУМа]] $(\{0,1\}^k, \leqslant)$ - *$k$-мерный куб*

>[!definition] Монотонная функция
>Функция $f(\vec{x})$ *монотонна*, если $f(\vec{x}) \leqslant f(\vec{y})$ для любых $\vec{x} \leqslant \vec{y}$
>если значения каких-то аргументов $f$ увеличить (подняться вверх по кубу), то значение $f$ не уменьшится
>множество всех монотонных б.ф. обозначается $\mathbf{M}$

>[!example] Примеры
>$0, \vee, \wedge, T_{i} \in \mathbf{M}$
>$+, \overline{}, \to, ’ \not\in \mathbf{M}$

>[!corollary] Лемма
>$\mathbf{M}$ - замкнутый класс

>[!proof]- Доказательство:
>рассмотрим формулу над $\mathbf{M}$, построим по ней схему
>подадим на входы произвольный битовый вектор, не равный $\vec{1}$
>на выходе каждого элемента схемы будет некоторый бит
>поменяем биты на некоторых входах с $0$ на $1$
>докажем, что ни у какого элемента выходной бит не поменялся с $1$ на $0$
>индукцией по максимальной длине $n$ пути от входа до элемента
>*Б.И:* $n = 1$
>входы элементов являются входами схема, элемент задает функцию из $\mathbf{M}$
>$\Rightarrow$ т.к. изменили только некоторые $0$ на $1$, выход не может уменьшиться
>*Ш.И:*
>входами элемента являются либо входы схема (не могли уменьшиться), либо выходы элементов с меньшей длиной пути (не уменьшились по предположению индукции)
>$\Rightarrow$ выходной бит всей схемы не уменьшился
>$\Rightarrow$ так как рассуждение верно для любого вектора на входе схемы, схема вычисляет монотонную функцию
