# Самодвойственные функции

>[!definition] Самодвойственная функция
>Функция $f(x_{1},\dots,x_{k})$ - *самодвойственна*, если $f(\overline{x}_{1},\dots, \overline{x}_{k}) = \overline{f(x_{1},\dots,x_{k})}$
>на противоположных наборах аргументов $f$ принимает разные значения
>множество всех самодвойственных б.ф. обозначается $\mathbf{S}$

>[!example] Примеры:
>$\overline{}, x+y+z, T_{2}(x,y,z) \in \mathbf{S}$
>$0, \vee, \to, \downarrow \not\in \mathbf{S}$

>[!corollary] Лемма:
>$\mathbf{S}$ - замкнутый класс

>[!proof]- Доказательство:
>рассмотрим формулу над $\mathbf{S}$, построим по ней схему
>подадим на входы произвольный битовый вектор
>на выходе каждого элемента схемы будет некоторый бит
>поменяем биты на всех входах
>докажем, что бит на выходе каждого элемента поменялся
>индукцией по максимальной длина $n$ пути от входа до элемента
>
>*Б.И:* $n=1$
>входы элемента являются входами схемы, элемент задает функцию из $\mathbf{S}$
>$\Rightarrow$ выходной бит изменился, так как поменялись все входы
>*Ш.И:*
>входами элемента являются либо входы схемы (поменялись по условию), либо выходы элементов с меньшей длиной пути (поменялись по предположению индукции)
>$\Rightarrow$ выход элемента, задающего самодвойственную функцию, поменялся
>$\Rightarrow$ в частности, поменялся выходной бит всей схемы
>$\Rightarrow$ так как рассуждение верно для любого вектора на входе схемы, схема вычисляет самодвойственную функцию
