# Линейные функции

>[!definition] Линейная функция
>Функция $f(x_{1},\dots,x_{k})$ *линейна*, если ее [[Многочлены над F_2#^e39158|полином Жегалкина]] - линейный
>т.е. $f(x_{1},\dots,x_{k}) = a_{0} + a_{1}x_{1} + a_{2}x_{2} + \dots + a_{k}x_{k}$ для некоторых $a_{0},\dots,a_{k} \in \{0,1\}$
>$f$ обладает свойствами самой обычной линейной функции из курса алгебры
>множество всех линейных б.ф. обозначается $\mathbf{L}$ 

>[!example] Примеры:
>$0, \overline{}, +, \sim \in \mathbf{L}$
>$\vee, \wedge, \to, \downarrow \not\in \mathbf{L}$

>[!corollary] Лемма:
>$\mathbf{L}$ - замкнутый класс

>[!proof]- Доказательство:
>рассмотрим формулу над $\mathbf{L}$, построим по ней схему
>каждый элемент схемы вычисляет линейную функцию своих входов
>линейная функция от линейных функций переменных является линейной функцией этих переменных
>$\Rightarrow$ вся схема вычисляет линейную функцию
