>[!property] Простейшие $O$-преобразования:
>$f(n) = O(f(n))$
>$C \cdot O(f(n)) = O(f(n))$, если $C$ - константа
>$O(O(f(n))) = O(f(n))$
>$O(f(n)) + O(g(n)) = O(|f(n)| + |g(n)|)$
>$O(f(n))O(g(n)) = O(f(n)g(n)) = f(n)O(g(n))$
>$\frac{1}{O(f(n))} = \Omega\left( \frac{1}{f(n)} \right)$

>[!proof]- Доказательство:
>$\frac{1}{O(f(n))} = \Omega\left( \frac{1}{f(n)} \right)$
>
>$O(f(n)) = \{h(n)| \exists n_{0} \in \mathbb{N}, C > 0 (\forall n > n_{0})(|h(n)|) \leqslant C||f(n)\}$
>$\Rightarrow \frac{1}{O(f(n))} = \left\{ \frac{1}{h(n)}| \exists n_{0} \in \mathbb{N}, C>0(\forall n > n_{0})(|h(n)|) \leqslant C|f(n)| \right\}$
>$|h(n)| \leqslant C|f(n)| \Leftrightarrow |\frac{1}{h(n)}| \geqslant \frac{1}{C} \cdot \frac{1}{|f(n)|}$
>$\Rightarrow \frac{1}{h(n)} = \Omega\left( \frac{1}{f(n)} \right)$ по определению

>[!example] Пример
>$\sum_{k=1}^n(k^2 + O(k))$
>$O(k)$ стоит под знаком суммирования, предел которого зависит от $n$
>$\Rightarrow O(k) = \{f(k,n) | \exists n_{0} \in \mathbb{N}, C > 0 (\forall n > n_{0}, k \leqslant n)(|f(k,n)| \leqslant Ck)\}$
>$\Rightarrow \sum_{k-1}^n (k^2 + O(k)) = \sum_{k=1}^n k^2 + \sum_{k=1}^n f(k,n) = \frac{1}{3}n^3 + \frac{1}{2}n^2 + \frac{1}{6}n + f(1,n) + \dots + f(n,n)$
>$\frac{|1}{2}n^2 + \frac{1}{6}n + f(1,n) + \dots +f(n,n)| \leqslant \frac{1}{2}n^2 + \frac{1}{6}n + C \cdot 1 + \dots + C \cdot n \leqslant D \cdot n^2$
>$\Rightarrow \sum_{k=1}^n(k^2 + O(k)) = \frac{1}{3}n^3 + O(n^2)$
