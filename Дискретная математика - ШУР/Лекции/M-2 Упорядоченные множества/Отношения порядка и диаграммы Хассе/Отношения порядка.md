# Отношения порядка:

Бинарное отношение $\rho \subseteq A^2$ называется [[4. Archive/Введение в математику/Отношения/Отношения порядка#^f5e707|отношением порядка]], если оно
- *рефлексивно*
	- $a \rho a \ \forall a \in A$
- *транзитивно*
	- $a \rho b, \ b \rho c \Rightarrow a \rho c \ \forall a,b,c \in A$
- *антисимметрично*
	- $a \rho b, \ b \rho a \Rightarrow a = b \ \forall a,b \in A$
	- антисимметричность не то же самое, что отсутствие симметричности!
- Для отношений порядка обычно используется инфиксная запись
	- и значки, похожие на $\leqslant: \ \subseteq, \preceq, \trianglelefteq, \sqsubseteq, \dots$
	- для записи условия $(a \preceq b \text{ и } a \neq b)$ используется запись: $a \prec b$
- *Упорядоченное множество* (**ЧУМ**) - это пара $(A, \preceq)$, состоящая из множества и отношения порядка на нем
*1)* $(\mathbb{N}, \preceq)$
 *2)* $(\mathbb{N}, |)$ делимость
 *3)* $(B(A), \subseteq)$
 - Если $a \preceq b$, то элементы называются сравнимыми, если ни $a \preceq b$ ни $b \preceq a$, то несравнимыми $a <> b$
- Эту структуру удобно рисовать, используя *отношение покрытия*
	- $a \vartriangleleft b$ ($b$ покрывает $a$), если $a \preceq b; a\neq b; a \preceq c \preceq b \Rightarrow (c=a \text{ или } c = b)$
- *Диаграмма Хассе* ЧУМа $(A, \preceq)$ - это *(ор)граф отношения покрытия* ^f37963
	- стрелки на ребрах диаграммы Хассе не рисуют
	- ориентация ребра определяется расположением вершин ниже/выше
	- это можно сделать, потому что граф - ациклический[^1]
- В бесконечных множествах отношение покрытия не всегда отражает порядок

[^1]: Ациклический значит, что в графе нет петель
