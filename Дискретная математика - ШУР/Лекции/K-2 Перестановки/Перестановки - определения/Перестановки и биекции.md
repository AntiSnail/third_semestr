# Перестановки и биекции

>[!definition] Перестановка
>*Перестановкой* множество $A$ называется произвольный [[Линейный порядок|линейный порядок]] на $A$

^bcdbef

>[!example] Пример:
>Пусть $A = \mathbb{N}$
>можно упорядочить по возрастанию $(\leqslant)$
>можно упорядочить по убыванию $(\geqslant)$
>можно упорядочить сначала все нечетные по $\leqslant$, а потом четные по $\geqslant$
>можно по сумме показателей в разложении на простые множители, а при одинаковой сумме - по $\leqslant$

>Если $A$ - *конечное*, перестановку можно определить как [[4. Archive/Матан/Коллоквиумы/Матан коллоквиум 1 сем/Вопросы/11 вопрос#Биективное отображение|биекцию]] $A$ на себя:
>$A = \{a_{1},\dots,a_{n}\} \Rightarrow$ нумерация элементов задает на $A$ линейный порядок
>перестановка - это линейный порядок $(a_{i_{1}}, \dots, a_{i_{n}})$
>$\Rightarrow$ определяет биекцию $f: f(a_{k}) = a_{i_{k}} \ \ \ \forall k$
>обратно, любая биекция $f: A \to A$ задает перестановку $(f(a_{1}),\dots,f(a_{n}))$
>
>*!* Для бесконечных множеств биекции задают не все перестановки
