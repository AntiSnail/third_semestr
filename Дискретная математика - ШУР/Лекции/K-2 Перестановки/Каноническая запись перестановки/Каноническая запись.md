# Каноническая запись

>Далее всюду $A$ - *конечно*; для удобства полагаем $A = [1\dots n]$
>Множество всех перестановок на $A$ обозначается $S_{n}$

>[!definition] Орбита элемента
>Цикл, в котором находится элемент $i$, состоит из элементов $i, \sigma(i), \dots, \sigma^{l-1}(i)$
>где $l$ - длина цикла
>здесь $\sigma^2 = \sigma \circ \sigma; \dots$
>т.е. $\sigma^2 = \sigma(\sigma(i));\dots$
>
>Этот цикл называется *орбитой* элемента $i$
>обиты различных элементов либо не пересекаются, либо совпадают

>[!corollary] Циклическая запись
>*Циклическая запись* перестановки неоднозначна:
>- выбор «первого» элемента в каждом цикле
>- перестановка циклов в записи
>- часто используется сокращенная запись: выбрасываются циклы длины $1$

>[!corollary] Каноническая запись
>*Каноническая запись* перестановки
>- каждый цикл записывается, начиная с наибольшего элемента
>- циклы выписываются по возрастанию первых элементов
>- сокращения не используются

>[!example]- Пример:
>$\sigma = (412)(5)(63)$ - *каноническая запись*
>$\sigma = (36)(241)$ - *неканоническая запись*
