# Биекция стирания скобок

>Пусть $\psi$ - функция *стирания скобок в канонической записи:*
>$\sigma = (i_{1},\dots,i_{l_{1}})(i_{l+1},\dots,i_{l_{2}})\dots(i_{l_{k}+1},\dots,i_{n}) \Rightarrow \psi(\sigma) = (i_{1},\dots,i_{n})$
>
>>[!example] Пример:
>>$\sigma = (412)(5)(63) \Rightarrow \psi(\sigma) = (4,1,2,5,6,3) = (6 \ 3 \ 2 \ 1 \ 4 \ 5)$

>[!theorem] Теорема
>Функция стирания скобок - биекция $S_{n}$ на себя

>[!proof]- Доказательство:
>Пусть $\pi = (i_{1},\dots,i_{n}) \in S_{n}$
>расставим в линейной записи $\pi$ скобки, чтобы получить *каноническую запись* (некоторой другой перестановки)
>$i_{1}$ принадлежит первому циклу, больше всех элементов в этом цикле и меньше первого элемента следующего цикла
>$\Rightarrow$ первый элемент $i’$ второго цикла однозначно определяется как самый левый элемент в линейной записи, больший $i_{1}$ (а значит, всех предыдущих элементов)
>аналогично, первый элемент $i’’$ третьего цикла однозначно определяется как самый левый элемент в линейной записи, больший $i’$ (и всех предыдущих)
>$\dots$
>каноническая запись восстанавливается однозначно
>
>*Пример:* $\pi = (4, 1, 2, 5, 6, 3) \Rightarrow \psi^{-1}(\pi) = (4 \ 1 \ 2)(5)(6 \ 3)$

>[!definition] Префикс-максимум
>Элемент, больший всех предыдущих в линейной записи перестановки, называется *префикс-максимумом*

>[!corollary] Следствие:
>в $S_{n}$ перестановок с $k$ циклами столько же, сколько перестановок с $k$ префикс-максимами
