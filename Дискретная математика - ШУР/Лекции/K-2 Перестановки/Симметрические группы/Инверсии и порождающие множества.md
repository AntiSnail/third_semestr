# Инверсии и порождающие множества

>[!definition] Инверсия
>Пусть $\sigma = (i_{1},\dots,i_{n})$ - перестановка в линейной записи
>Пара индексов $k < l$ называется [[4. Archive/Алгем/Лекции 2 семестр/лекции/5 лекция#^9984d6|инверсией]] (в $\sigma$), если $i_{k} > i_{l}$
>*число инверсий* $inv(\sigma)$ - важная характеристика перестановки
>особенно важна четность $inv(\sigma)$, называемая *четностью перестановки*
>
>($|A| = \sum_{\sigma \in S_{n}}(-1)^{inv(\sigma)}a_{1,\sigma(1)}a_{2},\sigma(2)\dots a_{n,\sigma(n)}$)

>[!definition] Транспозиция:
>Перестановка, меняющая местами *два элемента*, называется *транспозицией*
>- например $(1,2,5,4,3,6) \to (1, 2, 3, 4, 5, 6)$
>- транспозиция имеет один цикл длины $2$ и $n-2$ *неподвижные точки*
>- транспозиция - *нечетная* перестановка

>Группа $G$ *порождается* своим подмножеством $X$, если любой элемент из $G$ можно получить из элементов множества $X$ применением операций группы
>- если $G$ конечна, достаточно бинарной операции: $x^k = 1 \Rightarrow x^{-1} = x^{k-1}$

>[!theorem] Теорема:
>Группа $S_{n}$ порождается множеством всех транспозиций

>[!proof]- Доказательство:
>возьмем произвольную $\sigma = (i_{1}, \dots, i_{n})$ и применим *сортировку пузырьком*
>шаг сортировки переставляет два элемента ($=$ умножение на транспозицию)
>результатом сортировки является $\Delta = (1,\dots,n)$
>$\Rightarrow \Delta = \sigma \circ \tau_{1} \circ\dots\circ\tau_{k}$, где все $\tau$ - транспозиции
>$\tau^2_{i} = \Delta \Rightarrow \tau_{i}^{-1} = \tau_{i} \Rightarrow \sigma = \tau_{k} \circ \dots \tau_{1}$
