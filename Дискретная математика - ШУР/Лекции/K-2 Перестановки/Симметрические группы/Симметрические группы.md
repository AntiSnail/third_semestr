# Симметрические группы

>[!definition] Симметрическая группа
>Множество $S_{n}$ с операцией композиции образует [[Группы#^cb3475|группу]] - *симметрическую группу* $n$-элементного множества
>Композицию (произведение) перестановок удобно вычислять в *линейной записи*:
>если $\pi$ и $\sigma$ заданы массивами длины $n$, то $(\pi \circ \sigma)(i) = \sigma[\pi[i]]$

>$S_{n}$ *некоммутативна* при $n \geqslant 3$:
>$(2, 1, 3) \circ (3, 2, 1) = (2, 3, 1); \ \ \ (3, 2, 1) \circ (2, 1, 3) = (3, 1, 2)$
>
>Для любого элемента $a$ конечной группы $G$ существует $k$ такое, что $a^k = 1$
>найдутся $i < j$ такие, что $a^i = a^j$
>$\Rightarrow a^{-i}$ - обратный к $a^j \Rightarrow a^{j-i} = 1$

>[!definition] Порядок элемента
>Наименьшее число $k$ со свойством $a^k = 1$ называется *порядком* элемента $a$
>Порядок перестановки $\sigma \in S_{n}$ равен НОКу длин всех циклов в $\sigma$


>[!definition] Функция Ландау
>Наибольший порядок перестановки в $S_{n}$ называется *Функцией Ландау* и обозначается $g(n)$
>
>Поскольку длины циклов перестановки $\sigma \in S_{n}$ образуют числа $n$, $g(n)$ альтернативно определяют как максимальный НОК разбиения числа $n$

^c6e765

>Ландау доказал, что $g(n) \sim e^{\sqrt{ n \ln n }}$
>*Пример:* $g(9) =$ НОК$(4,5) = 20$, $g(10) =$ НОК$(2,3,5) = 30$

>[!corollary] Лемма:
>Пусть $ord(a) =d$, если $a^k = e$, то $d|k$

>[!proof]- Доказательство:
>$a^d = e, \ a^k = e$
>по [[теореме о делении с остатком]]
>$k = dq + r, 0 \leqslant r < d$
>
>$e = a^k = (a^d)^qa^r = e^qa^r = a^r$
>
>Противоречие, получили при $r<d \ a^r = e$, т.е. $d$ не порядок
>
